❓ COMMON QUESTIONS & ANSWERS
═══════════════════════════════════════════════════════════════════════════════

Q: Where do I start?
A: Read GET_STARTED.md first. It has everything you need step-by-step.

Q: How long will setup take?
A: 10-15 minutes total (5 for credentials, 10 for setup)

Q: What do I need before starting?
A: Supabase account (free), OpenAI API key (free $5 credit), Node.js installed

Q: Where do I get credentials?
A: 
   • Supabase: https://app.supabase.com → Settings → Database
   • OpenAI: https://platform.openai.com/api-keys
   See GET_STARTED.md for detailed steps.

Q: What if I get errors?
A: Check GET_STARTED.md "Troubleshooting" section or COMMANDS.md

Q: Can I run this on my computer?
A: Yes! Just follow GET_STARTED.md. Works on Windows, Mac, Linux.

Q: Is this ready for production?
A: Almost! See TASKMASTER_AI_SETUP.md "Before Production" section.

Q: How do I deploy?
A: See TASKMASTER_AI_SETUP.md "Deployment" section or README.md

Q: What's the tech stack?
A: React 18 + Vite + Express + PostgreSQL + OpenAI. See README.md

Q: How does the AI work?
A: Uses OpenAI GPT-3.5-turbo API. See TASKMASTER_AI_SETUP.md for details.

Q: What if I forgot my database password?
A: Reset it in Supabase Settings → Users → postgres. See GET_STARTED.md.

Q: Can I use a different database?
A: No, this uses PostgreSQL via Supabase. But you could modify the code.

Q: Do I need to pay for anything?
A: 
   • Supabase: Free tier included
   • OpenAI: $5 free credit
   • Node.js: Free
   • So: Totally free to start!
