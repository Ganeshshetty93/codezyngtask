🆘 COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

ISSUE: "Database connection failed"
SOLUTION:
   1. Check SUPABASE_DB_URL in .env
   2. Verify password is correct (not [YOUR_PASSWORD])
   3. Reset DB password if needed in Supabase Settings
   4. Check host matches: pfqrvqayboguojwtyukf.supabase.co

ISSUE: "OpenAI API error"
SOLUTION:
   1. Verify OPENAI_API_KEY in .env (starts with "sk-")
   2. Check OpenAI account has credit remaining
   3. Verify API is enabled for your account
   4. Try generating a new key if needed

ISSUE: "Port 5000/3000 already in use"
SOLUTION:
   Windows PowerShell:
   netstat -ano | findstr :5000
   taskkill /PID <PID> /F

ISSUE: "Frontend can't connect to backend"
SOLUTION:
   1. Verify backend is running (check terminal)
   2. Check http://localhost:5000/api/health
   3. Clear browser cache (Ctrl+Shift+Del)
   4. Check browser console (F12) for errors

ISSUE: "Dependencies not installed"
SOLUTION:
   cd backend && npm install
   cd ../frontend && npm install
