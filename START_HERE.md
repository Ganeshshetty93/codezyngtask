## 📞 Need Help?

### Issue → Solution
| Problem | Solution |
|---------|----------|
| Backend won't start | Check MongoDB connection, see QUICKSTART.md |
| Frontend won't start | Delete node_modules, run npm install |
| Can't login | Check .env file, verify MongoDB data |
| API not working | Check server terminal for errors |
| Styling looks broken | Check Tailwind config in frontend folder |
| Port already in use | Change PORT in .env file |

**More help:** See QUICKSTART.md Troubleshooting section
